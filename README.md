# Freelance CRM

Небольшая CRM для фрилансера: клиенты, сделки, воронка и краткая статистика.

## Что есть в проекте

- список клиентов с поиском и фильтром по статусу;
- карточка клиента, редактирование и заметки;
- сделки с суммой и этапом воронки;
- дашборд с основными показателями;
- адаптивная HTML/CSS-верстка;
- SQLite по умолчанию, `DATABASE_URL` можно заменить.

## Запуск

Python 3.11
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

CRM откроется по адресу `http://127.0.0.1:8000`.


Проект рассчитан на локальное использование и учебные цели. Перед публичным размещением стоит добавить авторизацию, CSRF-защиту, миграции и резервное копирование базы.
